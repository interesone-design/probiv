# Telegram PokeBot

Telegram-бот для поиска информации о людях по различным параметрам.

## Функционал

- 🔍 Поиск по ФИО (полное или частичное)
- 📞 Поиск по номеру телефона
- 📍 Поиск по местоположению
- 🧾 Поиск по другим параметрам

## Установка

1. Склонируйте репозиторий:
```bash
git clone <путь_к_репозиторию>
cd telegram_pokebot
```

2. Создайте виртуальное окружение и активируйте его:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Получите токен у @BotFather в Telegram и установите переменную окружения:
```bash
export TELEGRAM_BOT_TOKEN="ваш_токен_здесь"
# или на Windows
set TELEGRAM_BOT_TOKEN=ваш_токен_здесь
```

## Запуск

### Способ 1: Прямой запуск
```bash
python run_bot.py
```

### Способ 2: Использование setup скрипта
```bash
python setup.py
```

### Способ 3: Пошаговая настройка
1. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ````
2. Активируйте его:
   - Linux/Mac: `source venv/bin/activate`
   - Windows: `venv\Scripts\activate`
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Задайте токен в переменной окружения:
   ```bash
   export TELEGRAM_BOT_TOKEN=ваш_токен_здесь
   ```
5. Запустите бота:
   ```bash
   python run_bot.py
   ```

## Использование

Отправьте боту сообщение в одном из следующих форматов:

- `Поиск: Иванов Иван Иванович`
- `Телефон: +79123456789`
- `Местоположение: Москва`

## Структура проекта

- `bot.py` - основной файл бота
- `handlers/` - обработчики команд и запросов
- `utils/` - вспомогательные функции
- `models/` - модели данных

## Настройка

Для подключения к реальной базе данных измените файл `handlers/search_handler.py` и реализуйте подключение к вашей СУБД.
